# Image Gallery

A responsive and interactive image gallery built using HTML, CSS, and JavaScript.

## About

This project is a responsive image gallery that allows users to browse images in a clean and user-friendly interface. It includes category filtering, a lightbox preview, navigation controls, and responsive design for different screen sizes.

## Features

- Responsive image gallery
- Category filtering
- Lightbox image preview
- Next and Previous image navigation
- Keyboard navigation
- Hover effects
- Responsive layout for desktop, tablet, and mobile
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
